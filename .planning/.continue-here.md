# BLOCKING CONSTRAINTS - Read Before Anything Else

> These constraints were discovered through actual GitHub Actions failures.

- [ ] Validate every workflow edit with `actionlint` before pushing. GitHub rejected the first workflow because `runner.temp` was used in job-level `env`; that context is only valid at step level.
- [ ] Normalize tolerated native exit codes in PowerShell. A successful no-match `git grep` left `$LASTEXITCODE=1`, and the GitHub shell wrapper failed the otherwise successful step.
- [ ] Keep vcpkg repository and tool identities distinct. CI checks out registry baseline `fc3be1...`; bootstrap produces tool version `4b3e4c...`. The tool hash is not a valid `microsoft/vcpkg` Git commit.
- [ ] Do not restore `--release` to the Qt 6.5.3 MinGW `windeployqt` command. It misclassifies the platform plugins and exits with `Unable to find the platform plugin`; auto-detection deploys the Release runtime correctly.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|----------------------|
| Pushing unvalidated workflow expressions | Job-level `${{ runner.temp }}` produced a zero-job Actions run. | blocking | Run actionlint on `.github/workflows/windows-ci.yml` before every push. |
| Leaving an accepted native nonzero code active | `git grep` exit 1 meant no legacy references, but GitHub propagated the stale exit code. | blocking | After explicitly accepting a native nonzero result, set `$global:LASTEXITCODE = 0` or end with a known-success native command. |
| Confusing vcpkg source and tool commits | Checkout tried the executable tool hash and upstream rejected it as an unknown ref. | blocking | Checkout `fc3be1eb...`; separately let `windows-local.ps1` validate tool version `4b3e4c...`. |
| Forcing Qt deployment mode | Qt 6.5.3 MinGW found no release platform plugin when `--release` was supplied. | blocking | Keep the pending auto-detect invocation and verify `platforms/qwindows.dll` in the staged ZIP. |
| Replacing user-owned files | `tests/auto/` is untracked user content. | advisory | Never edit, stage, clean, or commit it. |
