## 本次修复

- `ProcessHarness::WaitReady` 在发现进程退出后再观察一次探针，避免完成探针旧结果导致
  `T10-4PROC-10` 的 `harness-incomplete`。始终失败的就绪探针仍失败，退出不自动表示协议就绪。
- `E03-XMSG-08` 按生产分发层的身份保护合同验证断连；要求登录成功、完整请求已发送、
  响应前明确 EOF/reset，且伪造 UUID 无数据库记录。登录失败、超时、半帧和业务成功不能冒充拒绝。
  不把这里的断连误写为业务处理器的 `UnauthorizedSender` 响应，也未改动身份校验策略。
- develop 纯文档变更保留静态检查，未知或混合变更完整回归；旧 develop push 可取消。
  固定 Qt 安装复用缓存；Linux 正常全量复用 ABI 缓存，冷恢复改为显式手动参数。
  服务报告与业务报告独立验证，发布 MySQL 8 前置检查和失败日志保存同步完善。
- 文档统一 schema、SQLite、资源构建/打包/专项测试、协议来源及接口名称。
