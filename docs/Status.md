# 项目当前状态

截至 2026-11-12，已合并的开发基线为 [develop 的 1a235b6](https://github.com/devzyz/Chat/commit/1a235b618dcbdcfb0e3428639bc4cba630d8991e)，包含 PR #45。发行版本号由 [VERSION](../VERSION) 定义。

## 已合并的能力

| 范围 | 已实现与边界 |
| --- | --- |
| 账号与好友 | 注册、登录、重置密码、头像、本人资料、备注、好友申请/接受/拒绝/双向删除/重新添加、退出及切换账号 |
| 私聊与消息 | 文字、图片/视频/文件、UUID 幂等、持久化 outbox、送达/已读、离线补拉和重登恢复；同账号有限自动重连 |
| 群管理 | 建群、增删成员、退出、转让、改名/解散、代次与历史边界、群资源授权；20 人群、2 秒补拉，无群已读回执 |
| 桌面交互 | 本地历史/搜索、未读提醒、最新消息摘要排序、消息复制、会话草稿/附件/光标/撤销、统一退出确认 |
| 存储与部署 | MySQL 007、SQLite 6；升级前备份并显式迁移；手动服务地址、单账号单在线会话 |

PR #35 补齐断线保存、心跳超时和资源续传恢复。PR #40 退役独立 StatusServer；Gate 选服并签发凭据，Chat 和 Resource 直接向 Redis 校验。PR #41～#45 改进数据库查询、写入前的凭据复核与并发建聊；每条 TCP 连接固定归属一个业务分片，Redis、MySQL 与出站 gRPC 分池执行。见[服务职责](Architecture.md)和[并发与关闭合同](Concurrency.md)。

- 验证码服务已在无 MySQL 配置、无 MySQL 密码时通过配置与启动回归。Linux 服务构建图已检查，未执行 Linux 原生构建或真实多机 E2E；性能日志导出测试在本机创建符号链接时被 Windows 拒绝，未验证其断言。
- PR #45 分支的 Windows Release Server 六份报告通过 234 项；另通过双实例 TCP 与隔离 MySQL 的 10 项持久化测试。Redis 使用协议替身，这些结果验证顺序、容量和停机行为，不代表生产吞吐量。各提交的测试结果与限制见[阶段验证记录](history/DevelopmentHistory.md#至-pr-45-的阶段验证记录)。

- 局域网上线前还需真实多机、证书和防火墙部署、桌面与休眠恢复验收。已完成资源的引用感知清理及一致备份恢复演练尚未完成。
